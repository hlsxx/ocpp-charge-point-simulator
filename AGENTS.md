# AGENTS.md

## Quick start

```sh
cp config.toml.example config.toml
cargo run -- --mode dynamic --config-path config.toml
cargo run -- --mode idle --config-path config.toml
```

Both `--mode` (dynamic|idle) and `--config-path` are **required** flags.

## Build & verify

```sh
cargo check              # fast lint-equivalent
cargo build              # debug build
cargo build --release    # uses LTO thin, strip, panic=abort, codegen-units=1
cargo test               # no tests exist yet — fails on "no tests"
```

No test suite, no CI, no pre-commit hooks, no linter beyond `cargo fmt`.
Run `cargo fmt` before committing (2-space indent, set in `rustfmt.toml`).

## Workspace layout

| Crate | Path | Purpose |
|-------|------|---------|
| `ocpp-charge-point-simulator` | `app/` | CLI entrypoint (`main.rs` → `cli.rs` + `simulator.rs`) |
| `common` | `crates/common/` | Config types (`Config`, `ChargePointConfig`), `SharedData` |
| `ocpp` | `crates/ocpp/` | OCPP protocol: message generators, handlers, per-version modules |
| `cp` | `crates/cp/` | Charge-point runtime: WebSocket connect, dynamic/idle modes, session |

## OCPP version feature flags

Default is `ocpp1_6`. To use another version at build time, pass the feature:

```sh
cargo run --features ocpp2_0_1 -- ...
```

Feature flags on `ocpp` and `cp` crates must match. Only `ocpp1_6` has generator/handler implementations; `2_0_1` and `2_1` are stubs.

## Configuration

- `config.toml` is **gitignored** — always work from `config.toml.example`.
- Supported fields differ slightly between `config.toml.example` (source of truth) and `next.config.toml` (a working local config).
- `implicit_charge_points` generates N charge points with randomized intervals.

## Changelog

Generated by `git-cliff` per `cliff.toml` (conventional commits). Run:

```sh
git cliff --unreleased -p cliff.toml -o CHANGELOG.md
```
